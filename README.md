# Lumis

Sistema de gestão e monitoramento para colônias lunares, desenvolvido para a Global Solution FIAP 2026.

## Objetivo

O Lumis centraliza o monitoramento de recursos vitais da Colônia Artêmis — oxigênio, água, alimentos e energia — e integra um check-in emocional diário para acompanhamento de bem-estar em missões de longa duração.

## Funcionalidades

- Login biométrico demonstrativo
- Hub com alertas e atalhos principais
- Dashboard de recursos em tempo real
- Detalhe expandido para cada recurso
- Check-in emocional com sliders
- Perfil do habitante
- Notificações
- Configurações gerais

## Tecnologias

- HTML5 semântico
- CSS3 com variáveis, Grid, Flexbox e media queries
- JavaScript Vanilla com `addEventListener`
- Organização em arquivos separados

## Estrutura


Abra o arquivo `index.html` no navegador.
